📋 ما هو Admin Panel؟
====================

تطبيق منفصل تماماً عن الموقع الأساسي
مخصص للمدير فقط
يتصل بنفس قاعدة البيانات (subscriptions.db)


🚀 التشغيل
===========

1. شغّل الملف:
   RUN_ADMIN_PANEL.bat

2. افتح المتصفح:
   http://localhost:5001

3. سجّل دخول:
   اسم المستخدم: admin
   كلمة المرور: admin123


🔑 أول خطوة: غيّر كلمة المرور!
================================

افتح: admin_app.py
السطر 16-17:

ADMIN_USERNAME = "admin"
ADMIN_PASSWORD = "admin123"  ← غيّر هنا


📊 الوظائف المتاحة
===================

✓ إدارة المستخدمين
  - عرض الكل
  - تفعيل/تعطيل
  - حذف

✓ إدارة الاشتراكات
  - إنشاء جديد
  - تمديد
  - إلغاء

✓ إدارة الخطط
  - إضافة خطة
  - تعديل خطة
  - حذف خطة

✓ الإحصائيات
  - عدد المستخدمين
  - الاشتراكات النشطة
  - الإيرادات


🔄 كيف يتصل بالتطبيق؟
=======================

Admin Panel (Port 5001)
         ↓
  subscriptions.db ← قاعدة بيانات مشتركة
         ↑
التطبيق الأساسي (Port 5000)

أي تعديل في Admin يظهر فوراً للمستخدمين!


🌐 التحديثات عبر الإنترنت
===========================

بدون نت:
  ✓ يشتغل محلياً
  ✓ يقرأ من القاعدة المحلية

مع نت:
  ✓ يمكن نشر Admin على سيرفر
  ✓ المستخدمون يزامنوا بياناتهم


📦 Port Numbers
===============

التطبيق الأساسي: 5000
Admin Panel:      5001

(منفصلين تماماً!)


🔒 الأمان
==========

✓ صفحة دخول منفصلة
✓ بيانات دخول خاصة
✓ Session مشفّرة

للإنتاج:
  - غيّر secret_key
  - استخدم HTTPS
  - استخدم VPN للوصول عن بُعد


⚠️ مهم
=======

1. شغّل Admin فقط عند الحاجة
2. لا تشارك بيانات الدخول
3. احتفظ بنسخة احتياطية من subscriptions.db
4. غيّر كلمة المرور الافتراضية


💡 مثال استخدام
================

السيناريو:
1. عميل دفع 100 ج.م لاشتراك شهري
2. افتح Admin Panel
3. سجل دخول
4. اختر المستخدم
5. اضغط "تفعيل اشتراك"
6. اختر "شهري"
7. احفظ
8. العميل يشوف الاشتراك فوراً!


🆘 مشاكل؟
==========

Port مشغول:
  netstat -ano | findstr :5001

قاعدة البيانات مقفولة:
  اقفل التطبيق الأساسي أولاً

التحديث مش ظاهر:
  حدّث صفحة التطبيق الأساسي
