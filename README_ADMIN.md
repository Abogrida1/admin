# 🔐 Admin Panel - نظام منفصل لإدارة الاشتراكات

## ✨ ما تم إنجازه

تم إنشاء **تطبيق Admin Panel منفصل تماماً** عن التطبيق الأساسي:

### ✅ **المميزات:**

```
✓ تطبيق منفصل (Port 5001)
✓ واجهة تسجيل دخول خاصة
✓ متصل بنفس قاعدة البيانات
✓ أي تعديل يظهر فوراً للمستخدمين
✓ إدارة كاملة للاشتراكات
```

---

## 🚀 التشغيل السريع

### **الطريقة 1: تشغيل التطبيقين معاً**
```bash
RUN_BOTH.bat
```

### **الطريقة 2: تشغيل Admin فقط**
```bash
RUN_ADMIN_PANEL.bat
```

### **الطريقة 3: يدوياً**
```bash
# التطبيق الأساسي
python app.py

# Admin Panel (في terminal آخر)
python admin_app.py
```

## 🔄 كيف يعمل؟

### **السيناريو:**

```
1. المدير يفتح Admin Panel (Port 5001)
        ↓
2. يسجل دخول: admin / admin123
        ↓
3. يختار مستخدم (مثلاً: mostshar@gmail.com)
        ↓
4. يضغط "تفعيل اشتراك"
        ↓
5. يختار "اشتراك شهري"
        ↓
6. التعديل يُحفظ في subscriptions.db
        ↓
7. المستخدم يفتح التطبيق (Port 5000)
        ↓
8. يقرأ من subscriptions.db
        ↓
9. يشوف الاشتراك النشط فوراً! ✅
```

## 🔒 الأمان

### **التطبيق الأساسي (Port 5000):**
- بيانات دخول: إيميل + كلمة مرور
- الوصول للمنتجات والمخزون
- يقرأ فقط من الاشتراكات

### **Admin Panel (Port 5001):**
- بيانات دخول: admin + password
- إدارة كاملة للاشتراكات
- لا يصل للمنتجات

### **منفصلين تماماً:**
- Port مختلف
- Session مختلفة
- بيانات دخول مختلفة
